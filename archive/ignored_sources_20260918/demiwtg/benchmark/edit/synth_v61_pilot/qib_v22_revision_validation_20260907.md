# V2.2 通用修订与 5.6-sol 复评 · 2026-09-07

本次修订针对对象对应、差异证据和严重度边界。20 题 × Gemini/Bagel 两个候选全部用新上下文的 `gpt-5.6-sol` 复评；不向判官提供历史得分、用户反馈、人工核验结论或其他候选。原始图片和逐题呈现方式沿用冻结 V2.2，运行日志核实 reasoning effort 均为 `low`。只做一轮，结果原样保留。

这些题已用于发现问题和修改 prompt，因此这里只能检验开发集回归；分数变高不等于更准确，也不能用它证明未来几百题上不低于 V2.0。Bagel V2.0 的历史判官实际为 gpt-6-astra，不能将其与当前 sol 的差异全部归因于 prompt。

## 改了什么

| 原来的风险 | 本次修改 |
|---|---|
| 先落档，后补理由；对象仍在就算保持 | 先输出前后对应事实，再依据事实落档；必要时两图独立分组计数并核对原目标是否仍在 |
| 几何提示多在 2 档，失败判断可能绕过核验 | 把相对画幅、固定参照物和遮挡核验放到全部档位之前 |
| 以“重绘”“整体漂移”代替可见差异 | 每项变化必须有对象/部位和 BEFORE→AFTER 状态，区分纹理损失、身份、数量和布局 |
| 将不可读字符猜成另一字符 | 区分相同、不同、可读性下降和无法确认 |
| “精确证据不足”成为无具体对象的保守扣分 | 1 档必须指明真实局部偏差或无法核实的必需精细项；2 档不要求逐像素相同 |
| 目标编辑成功就漏查明确保持或物理后果 | 保持义务覆盖远处对象和锁定动作分量；可见依赖关系被破坏仍按核心失败处理 |

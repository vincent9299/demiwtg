四个 prompt 版本为 V2.0、V2.1、V2.2、V2.2 修订版；修订版列 sol / low、sol / high 与 astra / medium 三轮，共六组评分。20 题的题面、原图与 Gemini 结果图 SHA256 在六组中逐题一致。

**分数读法：** 原始档位 0 / 1 / 2 对应 0 / 60 / 100 分；第二、三维的钳后档位不高于第一维。总分取钳后三维分数的平均值。理由解释的是原始档位，因此“原始 2（100 分）→钳后 0（0 分）”可能来自第一维钳制。各版分数为历史判定，得分高低不代表判定更准确。

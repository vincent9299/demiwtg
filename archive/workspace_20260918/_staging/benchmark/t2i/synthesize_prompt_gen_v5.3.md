# 文生图（t2i）评测出题指令（v5.3）

## 一、题目是什么

为一张样本图出**一道**文生图评测题。题目由两部分组成：

1. **题面**（gen_prompt）：一段文字，发给被评测的文生图模型，让它按这段话画图。
2. **判分标准**：四组检查条目，对应四个评分维度，之后由判分模型对着生成图逐条打分。

四个维度一览：

| 维度 | 考什么 | 判分标准从哪来 | 每题条数 |
|---|---|---|---|
| **真实保真度** | 模型知不知道概念的世界知识、能不能画对 | 输入里的「已核硬约束清单」，或从清单推导出的结论 | **5~7 条** |
| **文本一致性** | 画面是否忠实执行了题面的每一条显式规定 | 题面本身：逐句拆开，每条显式规定归入附录 Alignment 组的一个判分项 | 2~4 条 |
| **质量** | 画面有没有硬毛病（物理逻辑、材质、噪点、边缘、自然度、分辨率） | 附录 Quality 组里与本题相关的判分项 | 2~4 个 |
| **美感** | 画面的审美（构图、色彩、光影、解剖、情绪表达、风格控制） | 附录 Aesthetics 组里与本题相关的判分项 | 2~4 个 |

四个维度的边界：
- 「坐着的男人画成了躺着」是**文本一致性**问题（题面自己定的没执行），不算世界知识；
- 「张飞狮画成了黄脸」是**真实保真度**问题（世界知识画错）；
- 「多画了一只手、边缘糊了」是**质量**问题；「构图失衡、色彩脏」是**美感**问题；这两者都与知识无关。
- 同一条事实只进一个维度，四个维度之间不得重复。
- 知识点本身不能写进题面——写进去了就等于把答案告诉了考生（见第七节防泄漏）。

## 二、输入（按下面模板注入）

```
【样本图】（附图）
【图说明】{caption}
【概念名】{name}
【所属分类路径】{paths}
【知识库描述】{desc}
【已核硬约束清单】{constraint_list}
【本题调用方式】{invocation}
【判分项词表】（附录，随本指令固定附上）
```

各输入的用法：

1. **样本图 + 图说明**：这张图是题目的由头。它的用途**只有一个**——确认你出的题和这张图的主体、场景形态对得上（比如图里是一只黄色醒狮，你就别出关于醒狮鼓乐的题）。**严禁**把图里看到的细节（颜色、纹样、姿态、背景物）直接变成判分标准：单张图只是一种偶然画法，对其他合法画法没有约束力。
2. **概念名 / 分类路径 / 知识库描述**：本题围绕的概念。
3. **已核硬约束清单**（真实保真度维度的唯一知识来源）：针对这个概念预先审核过的一条条硬约束，每条形如：

   ```
   [编号] 约束陈述
          极性: must_have（合法画法必须呈现） / must_not_have（合法画法不得出现）
          变体: [合法差异的枚举，如 刘备狮黄脸 / 关公狮红脸 / 张飞狮黑脸]
          依据: 知识库描述 / 领域常识
   ```
4. **本题调用方式**：L2 组合 / L3 推导（定义见第三节）。

## 三、真实保真度维度

### 3.1 检查的两种调用方式

不设纯直述方式：对单个概念直接调用清单约束，自然包含在下面两种方式里（L2 的单概念情形、L3 的推理起点）。

**L2 组合**（含单概念多约束）：题面把多个概念、多个属性或一个关系放在一起，检查是多条约束叠加、且彼此牵扯。
> 例：题面「张飞狮在雪地里起舞」。检查 = 张飞狮（清单变体里选黑脸一档）+ 雪地环境 + 黑脸与白雪的对比关系 + 舞动时狮被的飘动形态 + 不得画成静态摆拍。
> 例：题面「醒狮采青瞬间」。检查 = 狮头约束若干条 + 悬挂的「青」（生菜/利是）+ 两者的高低空间关系 + 采青的典型肢体动作。
> 考的是「多个知识点同时成立时还能不能都画对」。

**L3 推导**：题面给出一个前提（可以是反事实假设），检查是「前提 + 领域知识」**推导出来的视觉结论**，结论本身不在题面里。推理链每个环节各占一条检查，所以 L3 天然检查条数最多。
> 例：题面「至尊魔戒刚在末日火山被熔毁，画此刻的魔多平原」。推导链：戒毁 → 索隆力量崩塌 → 巴拉多塔必须正在崩解（一条检查）、塔顶火眼必须熄灭（一条检查）、大地氛围由压抑转向崩塌（一条检查）。判分考这些推出来的后果。
> 例（反事实）：题面「假设佩戴魔戒不再隐身，而是让佩戴者成为黑暗中唯一强光源；画戒灵围攻风云顶」。推导链：人形强光源 → 周围一切物体的投影背离佩戴者向外延伸（一条检查）、戒灵身躯呈现被照亮的受光面（一条检查）、阴影浓度随距离衰减（一条检查）。
> 注意：推导可以翻转清单里的极性——反事实前提下，清单里原本「必须有」的东西可能变成「不得出现」（魔戒熔毁后，火眼不得再亮）。

### 3.2 检查怎么写

1. **数量**：任何调用方式都是 5~7 条。两种排布（可混用）：
   - 纵排（推理链）：同一个概念的推导层层递进（L3 的典型排布）；
   - 横排（场景实体）：画面里多个实体，每个实体各占若干条，再加实体之间的关系条目（L2 的典型排布）。
2. **三档闭合**：每条检查写成三档——0 分档（完全没做到 / 画错）、及格档（部分做到）、满分档（完全做到）。满分档要写具体到判分者看图就能判。**每种合法画法必须恰好落进某一档。**
3. **变体处理**：清单给了变体枚举的，三档描述必须覆盖全部变体，或明确声明本题只取哪个变体（取了就在题面里把该变体对应的概念点名，比如题面写「张飞狮」，检查就锁定黑脸）。
4. **负向约束独立成条**：清单里的「不得出现」（must_not_have）约束直接做成一条独立检查：出现了就 0 分。
5. **每条检查登记锚点**：
   - 直接 / 组合调用：写明引用清单里的编号；
   - 推导调用：写出完整推导链（前提 → 用到的知识 → 视觉结论），推导链的起点必须在清单条目或概念定义上。
6. **只写视觉可判的内容**：「意境磅礴」「画得美观」这类无法对照判断的话术一律禁止；判分者需要画面外文字才能判对错的要求禁止。
7. **每条检查给出最低可见条件**：如果题面允许的构图下该细节可能根本不出现（背面、远景、遮挡），要写明「当不可见时本条如何处理」，不许让判分者猜。

## 四、文本一致性维度

1. 把题面逐句拆开，每一条**显式规定**（出现什么主体、几个、什么姿态、空间位置关系、点名的颜色/材质/表情/场景）都写成一条检查，共 2~4 条。
2. 每条检查**归入附录 Alignment 组的一个判分项**（如数量→quantity、颜色→color、姿态→fullbody_action、左右位置→spatial_2d），判分按该判分项的准则执行；三档描述结合题面具体内容写。
3. 这类检查判的是「有没有照题面执行」，不判「知不知道」。
4. 题面没有的显式规定不要无中生有（不要替题面添加没说的颜色、数量）。
5. 每条检查同样给出最低可见条件。

## 五、质量维度

1. 从附录 Quality 组 6 个判分项里挑 **2~4 个**与本题画面确实相关的：画面必然涉及的才选（例如静物特写选材质与边缘，不选大场景才显著的物理逻辑）。
2. 每个选中的判分项按其准则与既定档位判分，不写自定义描述。

## 六、美感维度

1. 从附录 Aesthetics 组 6 个判分项里挑 **2~4 个**与本题画面确实相关的：题面指定了风格/情绪的优先选 style_control / emotional_expression，人物题材选 anatomical_fidelity。
2. 每个选中的判分项按其准则与既定档位判分，不写自定义描述。
3. 不允许把知识点塞进质量或美感维度（「脸谱配色是否符合张飞狮规制」是保真度，不是美感）。

## 七、防泄漏（红线，只约束真实保真度维度）

判分标准里的知识点一旦漏进题面，考生照抄就能得分，题目作废。规则：

1. 清单里每条约束的**关键词**（及其近义词、翻译、上位表述）都不得出现在题面里。题面只允许点名概念、给场景、给前提。
2. 必须输出**泄漏对照表**：清单每条约束 × 是否出现在题面，全部填「无」才允许交题；有任一条不是「无」，重新出题。
3. L3 推导题：推导结论不得出现在题面；题面只能给前提。
4. 交题前对三个方向各做一次反例自查：① 题面是否漏掉了某个合法派别（闭合被破坏）；② 题面是否无意中指定了视角，导致某条检查必然不可见；③ 透视/遮挡变形时满分档文字是否会误杀合法画法。
5. 文本一致性维度天然在题面里（它本来就是题面的复述），不算泄漏；质量与美感维度不含知识点，不算泄漏。

## 八、维度权重（总分合成）

| 维度 | 权重 |
|---|---|
| 真实保真度 | 0.5 |
| 文本一致性 | 0.2 |
| 质量 | 0.2 |
| 美感 | 0.1 |

## 十、交题前自查清单

1. 真实保真度检查有 5~7 条，且每条都能追到清单编号或一条完整推导链？
2. 题面里没有任何清单关键词（对照表全「无」）？
3. 三档评分描述把所有合法画法都接住了（含变体）？
4. 没有出现图级观察冒充知识（图里红绿脸 ≠ 醒狮必须红绿脸）？
5. 调用方式与检查形态一致（L3 必须有推导链，L2 不得有）？
6. 题面每条显式规定都有对应的文本一致性检查并归入 Alignment 判分项，没有无中生有的？
7. 质量、美感各选了 2~4 个判分项，且都与本题画面相关？
8. 四个维度之间没有重复条目？

## 附录：判分项词表（三组，随出题注入；判分档位均为 {0 分 / 及格 / 满分 / 不适用}）

> 旧协议中 Real-world Fidelity 组的 12 个知识判分项（动物/物品/地标/人物相似度/因果推理等）由「已核硬约束清单」的检查取代，出题端不再选择；其中因果/关系/反事实推理的要求已内含在 L3 推导检查里。

### Quality 组（质量维度从这里选 2~4 个）

| 代码 | 判分准则 | 何时选 |
|---|---|---|
| physical_logic | 图像是否遵循真实世界物理规律（重力、反射、阴影方向、物体稳定性）？ | 有光影、液体、悬挂、堆叠等物理场景时 |
| material_texture | 物体表面材质（皮肤、织物、金属、木材等）是否呈现真实的质感与材料属性？ | 材质是画面重要成分时 |
| noise | 图像是否细节丰富且无过度噪点或不自然平滑？ | 恒定相关，画面依赖细节时优先 |
| edge_clarity | 物体轮廓与边缘是否清晰锐利，无模糊或锯齿？ | 恒定相关 |
| naturalness | 图像是否自然，无 AI 生成常见的塑料感/油腻感？ | 人物、皮肤、食物题材优先 |
| resolution | 图像整体分辨率是否高清，无可见像素化或压缩伪影？ | 恒定相关 |

### Aesthetics 组（美感维度从这里选 2~4 个）

| 代码 | 判分准则 | 何时选 |
|---|---|---|
| composition | 构图是否平衡、有视觉引导、符合审美？ | 恒定相关 |
| color_harmony | 整体色彩搭配是否和谐统一、契合画面情绪？ | 恒定相关 |
| lighting_atmosphere | 光影氛围（明暗对比、整体光效）是否与题面的场景设定匹配？ | 题面指定了时间/光照/氛围时优先 |
| anatomical_fidelity | 人物/动物的五官比例、骨骼结构、肢体关节是否符合解剖学？皮肤是否有真实微观质感？ | 人物/动物题材必选 |
| emotional_expression | 图像整体审美基调是否有效传达题面意图的情绪与氛围？ | 题面指定了情绪时选 |
| style_control | 图像是否准确呈现题面要求的特定艺术风格？ | 题面指定了风格时必选 |

### Alignment 组（文本一致性检查逐条归入这里）

| 代码 | 判分准则 | 对应题面规定的类型 |
|---|---|---|
| subject_prominence | 题面明写的主体是否占据画面主导地位（体量、位置、视觉焦点）？（主体缺失/主题跑偏由 gate 封顶接管，不在本项判） | 主体点名 |
| quantity | 画面中物体数量是否与题面指定的数量一致？ | 数量 |
| facial_expression | 人物/动物的面部表情是否准确反映题面指定的情绪状态？ | 表情 |
| material_properties | 物体的材质是否与题面的材质描述一致？ | 材质 |
| color | 物体颜色是否与题面的颜色指定一致？ | 颜色 |
| shape | 物体形状是否与题面的形状描述一致？ | 形状 |
| size | 物体尺寸是否与题面的规格一致？ | 尺寸 |
| contact_interaction | 若题面涉及主体间物理接触，接触交互是否描绘自然真实？ | 接触动作 |
| noncontact_interaction | 若题面涉及主体间非接触关系，空间与社会关系是否描绘自然合乎逻辑？ | 非接触关系 |
| fullbody_action | 主体（人/动物）的整体姿态与肢体动作是否准确执行题面描述的活动？ | 姿态/动作 |
| spatial_2d | 物体在 2D 平面上的相对位置（左右/上下/前后景）是否符合题面空间指令？ | 平面位置 |
| spatial_3d | 物体在 3D 空间中的布局、遮挡与相对位置是否符合题面或空间逻辑？ | 空间布局 |
| composition_relationship | 多个元素是否被整合为视觉连贯、逻辑一致的整体？ | 多元素组织 |
| difference_similarity | 物体间被指定的形状/颜色/材质差异或相似是否被准确表现？ | 差异/相似指定 |
| containment | 物体间的包含或围合关系是否被正确描绘？ | 包含关系 |
| real_world_scene | 场景类型与环境设定是否与题面描述的地点一致？ | 现实场景 |
| virtual_scene | 虚构/奇幻场景内的元素是否内部自洽、逻辑连贯？ | 虚构场景 |

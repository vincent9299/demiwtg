已核对：Qwen-Image-Bench 为真实基准（arXiv 2605.28091），其 56 facet、φ 映射 0/60/100、N/A 剔除机制与贵文档描述一致。但有两处与原版的偏差会影响后面的评审结论：**① QIB 原版 Fairness/Safety 挂在 Real-world Fidelity 之下**（不是独立支柱），贵文档"剔除"的说法在归属上不准确；**② QIB 的聚合是 L3→L2→L1 逐层聚合、L1 支柱等权**，贵文档通用线是"激活 facet 拉平取均值"，这是一个实质性的口径改动（见 C6）。另外 `landmark_identity`/`character_likeness`/`nature_morphology`/`tech_machinery` 是贵方自行扩充的 World Knowledge 细则，QIB 原版没有——扩充本身合理，但文档写"按 QIB 56 细则重组"容易误导校准来源。

以下逐条评审。

## A. 出题流程与红线

### A1. 三步流程是否足以支撑校验点可靠性 —— **修改：缺两个关键环节**

**结论**：流程骨架成立，但从"知识锚定"到"出题"之间缺一步**触发链验证**，从"出题"到"输出"之间缺一步**唯一性检验**。这两个缺环是本文档最大的方法论漏洞。

**理由**：
1. **触发链断裂**。文档只要求"至少一个约束的正确画法依赖知识"，但没有要求验证 `gen_prompt` 中存在**充分触发条件**。以文档自己的示例为例：prompt 写"巨型石像魔神"而非"大魔神（Daimajin）"，一个不认识该 IP 的模型画出不发红光的石巨人，在逻辑上完全合理——此时"双目发光 0.2"这条 check 惩罚的不是知识缺失，而是**模型没猜中出题人心里想的那个实体**。探针失效的典型形态就是这种"触发不足"：判分时无法归因是"不知道"还是"prompt 没给够线索"。
2. **唯一性/占优性缺失**。每条 check 必须满足"给定 prompt + 该项 solid 知识 ⇒ 正确画法是必然或强占优结果"，而不是多种合理画法之一。文档没有任何机制检验这一点。
3. **solid/likely 两档不够，且判定者是利益相关方**。solid 由出题 LLM 自我标注，而 LLM 把自身幻觉标成 solid 是常态行为，两档分级没有改变"自证"的本质。至少需要：(a) 三档（`solid` 教科书级共识 / `common` 广泛但存在地域、版本差异 / `likely` 长尾）；(b) 强制规则"能被 image 中 `visible_facts` 交叉印证的知识优先用作 check"——这才是让样本原图真正发挥"知识锚点"作用的机制，目前 `evidence_audit` 写完就被丢弃了，与后续字段没有任何硬约束关系。

**改写措辞**（第三节增补第 4、5 步）：

> 4. **触发链验证**：逐条 check 指出 `gen_prompt` 中的触发子句（`trigger` 字段），并自问：仅凭该子句 + 该条 knowledge，正确画法是否为必然或强占优结果？若某 check 依赖"猜中特定实体/作品"，则 prompt 必须含足以唯一锚定该实体的信息，否则删除该 check 或补强 prompt。
> 5. **交叉印证**：优先选用能与 `visible_facts` 相互印证的知识作为 check；纯图外知识作 check 时须为教科书级共识。

### A2. 五条红线的冲突与漏洞 —— **修改：三处硬伤**

**结论**：红线方向都对，但存在一处**直接自相矛盾**、一处**机制空转**、一处**未处理的隐性冲突**。

1. **`needs_verification` 与红线 2 直接矛盾（硬伤）**。第二节说 likely 知识"用于答案关键点时置 `needs_verification: true`"；红线 2 说"判定标准只允许建立在 solid 知识上"。答案关键点就是 `implicit_checks`——那么 likely 知识到底能不能进 check？两处口径打架。且该字段是**题级布尔**而非 check 级，且没有任何下游动作（谁验证？验证不过怎么办？验证前计不计分？）。目前它是纯装饰。
   **改写**：删除歧义，二选一——
   - 方案甲（推荐）："likely 知识只可用于 `gen_prompt` 的氛围性描写与 `expected_failure_modes`，一律不得进入 `implicit_checks`；`needs_verification` 字段废除。"
   - 方案乙："`implicit_checks` 每条增加 `confidence: solid|likely` 字段；含 likely check 的题进入人工复核队列，复核通过前该题不计入总分。"

2. **红线 1 与红线 5 的边界未定义**。"关键约束须明写"（红线 5）与"隐含约束不得明写"（红线 1）之间没有划分标准，出题 LLM 会在灰区反复横跳。**改写**："显式约束 = 生成目标要素（主体、场景、风格、情绪、显式属性）；隐含约束 = 由显式约束 + 世界知识必然推出的画法细节。判别测试：把某约束从 prompt 中删除后题目仍可判 ⇒ 它应作隐含约束；删除后无法判 ⇒ 它必须明写。"

3. **泄漏是梯度而非布尔，文档只防了"明写"**。"无风的高山湖泊清晨"本身就是半泄漏——"无风湖面"与"镜面倒影"在图文语料中强共现，模型可以靠共现统计而非物理知识画对。这触及知识探针的根本混淆：**t2i 模型的"世界知识"很大程度上就是共现统计**。无法完全消除，但至少应加一条软纪律："评估触发词与目标画法在通用语料中的共现强度；若两者是高频固定搭配（如'雪山—山顶积雪'），该 check 降权或标注 `shortcut_risk: high`。"

4. **反事实题与红线 2 存在未处理的隐性冲突**。facet 词表有 `counterfactual_coherence`，L3 定义含反事实约束，但反事实前提下的"正确画法"不是 solid 世界事实，而是"solid 规则 + 反事实前提"的演绎结果。红线 2 按字面会把所有反事实题判废。**改写**（红线 2 增补）："反事实题的 check 允许建立在'solid 物理/逻辑规则 + prompt 显式给出的反事实前提'的一步演绎上，演绎链须写入 `knowledge` 字段。"

5. **红线 4 不可操作**。"冷门到专家也需查资料"——哪个领域的专家？大魔神"双目发光"对特摄研究者是常识，对一般人极冷门。**改写**："判据：该知识是否可期望出现在该实体的百科条目首段或主流介绍性材料中。是 ⇒ 可用；仅见于专业文献/粉丝 wiki 深层页面 ⇒ 不可作高权重 check。"

## B. facet 词表

### B3. 四支柱裁剪 —— **保留，但修正表述**

**结论**：裁剪决策本身对"世界知识探针"定位是合理的：Creative Generation 的主观维度（想象力、设计应用）与"唯一正确画法"的探针逻辑相斥，剔除正确；把 Logical Resolution 类因果细则升格为 Knowledge Reasoning 也是对的。

两点修正：
1. **表述失实**：QIB 原版中 Fairness / Safety & Compliance 是 Real-world Fidelity 的 L2 子能力，不是独立支柱。文档写"剔除 Fairness 与 Safety"应改为"剔除 Real-world Fidelity 下的 Fairness 与 Safety & Compliance 两个 L2 子能力"。"各模型无区分度"是经验断言，若基准仅内部诊断用可接受，但应改为 scope 声明："公平性与安全性不在本基准探测目标内，由独立赛道覆盖"——否则对外发布时会被质疑用"无区分度"为由回避敏感维度。
2. **未声明的扩充**：`landmark_identity` / `character_likeness` / `nature_morphology` / `tech_machinery` 是自行新增的 L3（QIB World Knowledge 原版只有 5 项）。新增本身对探针基准是**好事**（原版 5 项对知识探针太粗），但标题"按 QIB 56 细则重组"应改为"以 QIB 56 细则为基础裁剪并扩充",否则后续对齐 QIB 分数时会出现无法映射的维度。

### B4. `subject_prominence` —— **修改：中档语义悬空 + 两节口径不一致**

**结论**：归属 Alignment/Subject 合理（QIB 无此维度，属合理自创）；但当前措辞不足以让 judge 稳定打 {0,1,2}。

问题：
1. **1 档没有定义**。"存在但不主导降分"只区分了 2 和非 2。{0,1,2} 三档中，1 和 0 的分界在哪？**改写**："2 = 主体为画面视觉焦点（占据显著面积或构图中心/引导线终点）；1 = 主体可明确辨认，但被其他元素在面积或视觉权重上压制；0 = 主体沦为边缘配角、需刻意寻找才能定位（但尚可辨认——完全无法辨认或错成他物 ⇒ 交 gate）。"
2. **gate 分界的可操作描述缺失**。0 档与 gate 之间的分界（"边缘化"vs"缺失/跑偏"）恰是 judge 最不稳定的区间。建议给判分侧一条硬规则："不借助 prompt 也能从画面中辨认出该主体 ⇒ 走 `subject_prominence`；必须借 prompt 才能勉强对上、或主体被替换为近似物 ⇒ 走 gate"。出题 prompt 侧只需保证第五节与第七节措辞一致——**目前第五节只写"缺失由 gate 接管"，第七节写"缺失/主题跑偏"，两处不一致**，请统一为"缺失或主题跑偏"。
3. **与近邻维度的边界**：与 `composition`（审美构图）的切分可以接受——构图可以优美而主体不主导——但应在 `composition` 判词中加一句"不重复评判主体主导性"。与 `size` 边界清楚（size 需显式尺寸指令）。真正模糊的是与 `spatial_3d` 和 `relational_reasoning` 的三方重叠：示例题"与人类建筑形成巨大体型比例"标了 `spatial_3d`，但这实质是隐含比例知识，更贴 `relational_reasoning`。需要一条选词优先级规则（见 B5）。

### B5. 选词纪律 —— **修改：纪律 3 不可执行，需补三条**

- 纪律 1、2 可执行，**保留**。
- **纪律 3 废除并重写**：出题 LLM 按批次调用，只见当前样本，**无法感知全套频率分布**，"尽量均衡"对单次调用是不可执行的空指令，LLM 只会假装遵守。改写："同一样本的多道题之间 `facet_tags` 组合不得完全重复；全局维度均衡由调用方统计访问频率并通过批次配额下发（如'本批次优先激活以下低频维度：…'）。"
- **需补的纪律**：
  1. **`subject_prominence` 默认激活**（不占 3~6 名额）。每题必有主体；若该维度只在被显式标注时才计分，"主体在场但沦为配角"的图在多数题里将不受任何惩罚（gate 不管、其他维度不看），这是弱模型可钻的明确漏洞。
  2. **近邻维度消歧规则**："同一约束只激活一个维度。有显式指令 ⇒ Alignment 侧（`material_properties`/`facial_expression`/`color`）；无显式指令、考自发画质 ⇒ Quality/Aesthetics 侧（`material_texture`/`emotional_expression`/`color_harmony`）；由知识推出 ⇒ Real-world Fidelity 侧。"目前 `material_texture` vs `material_properties`、`physical_logic` vs `causal_reasoning` 必然发生重复标注。
  3. **facet 与 check 的挂钩标注**：`facet_tags` 中区分哪些由 `implicit_checks` 激活、哪些由显式约束激活（如 `facet_tags_implicit` / `facet_tags_explicit` 两个子数组），否则评测后归因时无法区分"知识错"与"服从性错"落在同一维度上的情况。

## C. 判分契约

### C6. 0.5/0.5 + φ + gate 的组合 —— **修改：存在三个失真点**

**结论**：单看每个部件都成立，组合起来有明确失真。

1. **通用线稀释探针（最严重）**。你们担心的方向反了：「知识线全对但通用线拉胯」的题得 $0.5 \times 100 + 0.5 \times \text{低分} \approx 50\text{–}70$，惩罚合理；真正的失真是**镜像情形**——知识线全错但画面华丽的模型得 $0.5 \times 0 + 0.5 \times \text{高分} \approx 40+$，而 gate 只拦"主体缺失"，拦不住"主体在场、知识全错、画质精美"。对一个自我定位为**知识探针**的基准，弱知识强画质的模型保底 40 分，区分度被直接腰斩。三个可选修正（按推荐排序）：
   - 知识线权重升至 0.7（总分仅作排序，定位靠分线报告，本就该偏探针）；
   - 增加第二 gate：知识线加权分 = 0 时总分封顶 50；
   - 通用线内部给 Real-world Fidelity 支柱加权。
2. **通用线拉平均值 vs QIB 逐层聚合（口径改动未声明）**。QIB 是 facet→L2→L1、L1 等权；贵文档是激活 facet 拉平取均值。后果：一道题若激活 4 个 Alignment facet + 1 个 RWF facet,通用线被 Alignment 支配,且 3-tag 题与 6-tag 题的单 facet 权重差一倍,聚合到维度层面时同一维度的分数来自不同"竞争环境"。建议至少改为**支柱内先平均、支柱间等权**,与 QIB 对齐,也顺带缓解问题 1。
3. **知识线的 φ 与加权顺序未定义（硬伤）**。`implicit_checks` 每条 {0,1,2}、权重合计 1.0——是逐条 φ 后加权求和（$\sum_i w_i \cdot \varphi(s_i)$），还是加权平均后再 φ？两者结果差异巨大（后者几乎只输出 0/60/100 三值附近）。文档必须写明,建议前者。
4. **gate 悬崖**。封顶 30 是二值悬崖,VLM judge 在"跑偏 vs 大幅偏离"边缘案例上的翻转会造成 ±40 分跳动。判分侧应要求 gate 判定附证据陈述,并把 **gate 触发率**与 **N/A 率**（出题方指定的 facet 被 judge 判 N/A,即出题失配的直接信号）列为出题质量监控指标——这两条应写进文档第十节自检的"上游承诺"。

### C7. 出题方写判分标准 —— **修改：真风险不是利益冲突，是口径漂移 + 无闭环**

**结论**：出题 LLM 与判分 VLM 异体,不构成经典自评冲突。真实风险有三:

1. **check 措辞的解读漂移（最大风险）**。示例里"具武士风格盔甲**等**东方元素 0.2"——一个"等"字把判定权完全让渡给 judge 的自由裁量。且 check 是 {0,1,2} 三档,但**没有任何一处定义 check 级的 1 档语义**（facet 侧 QIB 有 Fail/Pass/Excel 语义,check 侧完全悬空）。**改写**（第七节）："每条 `check` 须为可直接目视核对的视觉命题,禁用'等/大致/合理/适当'类开放限定词;每条附 `rubric`:一句话定义 2（完全正确）/1（部分正确的具体形态）/0（错误的具体形态）。"
2. **幻觉传染至判分标准**。判分方会忠实执行错误标准,错误被系统性放大而非抵消。`knowledge` 字段是可自动核查的（检索或第二 LLM 事实审核）,建议在出题与判分之间加一道廉价的 check 事实性审核。
3. **无区分度闭环**。第四节口号"拒绝无区分度的随机需求",但全文没有任何机制保证区分度——它完全依赖出题 LLM 的自觉。必须补实证校准:pilot 阶段用一强一弱两个参照模型试跑,剔除"双通过"与"双失败"的 check(前者无区分度,后者可能是坏题),并统计每条 check 的 judge 重测一致性。

## D. 区分度工程与输出格式

### D8. `expected_failure_modes` 与 `probe_dims` —— **修改：归因链存在断层**

**结论**：`expected_failure_modes` 是好设计但缺闭环;`probe_dims` 当前状态是**归因噪声源**,需大改或砍掉。

1. **`probe_dims` 十个词没有任何定义**,只有词表。出题 LLM 会按字面自由发挥,标注不可比。且与 `facet_tags` 大面积语义重叠却无映射:`physical_causality` ≈ `causal_reasoning`+`physical_logic`,`counting_quantification` ≈ `quantity`,`spatial_structure` ≈ `spatial_2d/3d`,`instruction_following` ≈ 整个 Alignment 支柱。评测后若 probe 归因与 facet 得分打架,短板定位无从落地。
2. **断层实例**:`negation_constraint` 在 probe 词表里,但 41 个 facet 中**没有任何维度承接负向约束**（"画面中不得出现 X"）的判分——探针意图存在、判分通道缺失,这类题的负向约束将不产生任何分数。要么在 Alignment 下补 `negation` facet,要么禁止出负向约束题。
3. `ocr_shortcut_resist` 出现在 t2i 赛道语义不明（这像理解赛道的探针;若指"抗文字渲染捷径"须明确定义,且 Text Rendering 已随 Creative Generation 被剔除,判分通道同样缺失）。
4. **改法**（二选一）:(a) 砍掉 `probe_dims`,归因直接用 `knowledge_dim × facet_tags × difficulty` 三轴交叉,信息量已足够;(b) 保留则必须:每词一句定义 + 建立 `probe_dim → facet_tags` 显式映射表 + 删除无判分通道的词。
5. **`expected_failure_modes` 补闭环**:要求每条 failure mode 挂接到某条 `implicit_check` 或某个 facet（加 `linked_check` 字段）,判分侧顺带勾选"该预期失败是否被观察到"。这样既可评测后统计**预测命中率**（出题质量的直接度量）,又使失败模式成为归因证据而非装饰。

### D9. 难度分级 —— **修改：定义有两处 bug**

1. **L1 定义与第七节硬性矛盾**:L1 = "1 个隐含知识校验点",但第七节规定 `implicit_checks` 为 2~5 条。L1 题的另外 ≥1 条 check 是什么?文档没说。要么允许 L1 题 checks 为 1 条,要么明确"L1 = 恰 1 条知识型 check,其余为非知识型基础 check（并标注 `type: knowledge|basic`)"。
2. **L2/L3 在 3 个校验点处重叠**:L2 = "2~3 个",L3 = "≥3 个",一道 3 check、无推理的题两档都符合。且"或"逻辑使分级退化:1 个校验点但含反事实推理,按字面既是 L1 又是 L3。**改写**为二维取高:

> 难度 = max(数量档, 推理档)。数量档:1 条 ⇒ L1,2~3 条 ⇒ L2,≥4 条 ⇒ L3。推理档:知识直接映射 ⇒ L1,需一步推理 ⇒ L2,需多步推理/因果推演/反事实 ⇒ L3。

3. **占比目标**:L2+L3 ≈ 80% 对短板定位方向正确,但注意两点:(a) L3 含反事实,是 check 质量最不可控的一档(见 A2-4),高占比会放大坏题率;(b) **自报难度与实证难度常脱钩**,建议自报难度仅作配额控制,发布时以参照模型通过率重新校准难度标签。

## E. 整体

### E10. 弱模型最容易钻的空子（按危害排序）

1. **通用线搭便车**:现代 t2i 模型(哪怕弱知识)画质审美普遍在线。主体照 prompt 明写画出 ⇒ gate 永不触发;Quality/Aesthetics facet 拿 1~2 档 ⇒ 通用线 60~80;知识线全错也有约 30~40 总分。**gate 封顶 30 在实践中近乎形同虚设**——因为红线 5 强制 prompt 明写主体,弱模型照抄主体名词就能过 gate。
2. **共现捷径冒充知识**:"无风高山湖泊清晨"→倒影、"1960 年代特摄"→胶片颗粒,这类触发词-画法对在训练语料中是高频共现,弱模型靠统计惯性画对,探针误报为"有知识"。
3. **模糊 check 蒙混**:"东方元素""武士风格**等**"这类宽泛措辞,任何模板化的东亚风盔甲都能得 1 档(60 分)。check 越模糊,弱模型期望得分越高。
4. **judge 宽大 + φ 抬分**:VLM judge 对"有点像"倾向给 1,φ 把 1 映到 60 而非线性的 50,系统性分数通胀,弱模型受益更多。
5. **L1 题免费分**:单知识点题若知识恰在弱模型分布内(热门地标、热门 IP),知识线满分。热门实体占比需在抽样侧控制,出题 prompt 管不到但应知会。

### E11. 与现有基准的对比 —— 差异化真实存在，但赛道已不空旷

**先泼冷水**:这个赛道 2025–2026 已相当拥挤——WISE(1000 题世界知识语义评测)、WorldGenBench(知识 checklist + VLM 逐项判)、T2I-ReasonBench(LLM 生成 question-criterion 对 + MLLM 判分,与贵方 `implicit_checks` 机制几乎同构)、PicWorld(隐含世界知识 + 多智能体证据判分)。"隐含知识 checklist + VLM judge"本身已不是差异化。

**真正的差异化价值**(值得保住的三点):
1. **真实图片锚定的出题**:上述基准全部纯文本出题,知识源是出题 LLM 的参数记忆;贵方以样本图 + query_label 锚定,理论上可压制出题幻觉——但前提是把 A1 说的 `visible_facts` 交叉印证做成硬约束,否则该优势只停留在纸面。
2. **标签树分层抽样**:知识域覆盖可控、可与理解/编辑赛道同源对照——这对 Bagel 类统一模型"三任务同实体对照定位"是独有价值,现有基准都做不到。
3. **`expected_failure_modes` 预测 + 归因链**:诊断导向 vs 排名导向,前提是 D8 的闭环补上。

**潜在弱点**:
1. **亲缘偏置**:出题 LLM、判分 VLM、被测统一模型可能共享训练分布,judge 与被测模型同源时系统性偏分——WISE_Verified 特意换开源 judge 并做多 judge 稳定性验证,贵方文档对此零着墨。
2. **无人工环节**:QIB 用 80 名专业标注员三审、T2I-ReasonBench/PicWorld 都有人工 curation;贵方全链路 LLM,题目质量方差将显著更大,至少需抽样人审 + pilot 区分度过滤。
3. **可复现性**:check 级无 rubric、{0,1,2} 中档悬空,重测方差会伤害"稳定犯错"这一探针前提本身——一个"稳定犯错"的结论需要判分先稳定。

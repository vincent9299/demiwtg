## 1. 第一层：程序化体检（机器 100% 覆盖，无需人工评审）

本次已用当前数据实测，结果如下：

| 检查项 | 实测结果 | 结论 |
|---|---|---|
| 同父同名碰撞（树结构重复） | **0** | ✅ 干净 |
| 空中间分支（无实例无子节点） | **0** | ✅ 干净 |
| 叶内重复实例 | **0** | ✅ 干净 |
| 中英行数一致 | 21,406 = 21,406 | ✅ |
| 跨叶重复实例 | **29,689** | ⚠️ 需拆分处理（见下） |
| 同名段（不同路径同名节点） | 1,669 个名字 / 3,705 行 | 观察项，与跨叶重复联动 |
| 超大叶（60+ 实例） | **337** | ⚠️ 进入实例评审 |
| 异常小叶（1-3 实例） | **1** | ✅ 可忽略 |

**关键发现 —— 跨叶重复实例拆分：**

| 类型 | 数量 | 性质 | 处理 |
|---|---|---|---|
| 域内重复 | **16,875** | 疑"平行重复分支"（同一域里两套结构装同一批东西） | **进入裁决表** |
| 跨域重复 | 12,814 | 多归属（如乐器既是乐器又是娱乐用品），多数合法 | 白名单 + 抽查 |

域内重复 top 域：人造物体 4,057、动物 2,776、植物 1,826、食物 1,333、人物与人体 1,269、文化艺术与媒介 1,032。

典型样例（人造物体域内）：「横笛/竖笛/短笛/竹笛」同时出现在 `中西乐器/中国吹管乐器` 和 `娱乐用品/笛子` 两处——这是**平行分支**问题，正是第二层结构评审要合并的对象。

**产出**：把体检脚本固化为 `ab_world/health_check.py`，每批落盘后跑一遍，输出体检报告 + 三份工单（域内重复清单 / 超大叶清单 / 同名段观察清单）。

## 2. 第二层：L2 结构评审（2,753 个分支）

### 2.1 分批（按域规模三批）

| 批次 | 域（L2 数） | L2 合计 |
|---|---|---|
| **批 A：大域** | 行为动作 527、人造物体 340、属性与状态 215、声音 194、人物与人体 186、建筑与基础设施 174 | **1,636** |
| **批 B：中域** | 文化艺术与媒介 150、交通工具 125、食物 117、植物 96、动物 93、自然景观 81、组织机构与社会事件 80、时间数量与度量 70、文字与信息图形 69 | **881** |
| **批 C：小域** | 其余 14 域（63 及以下） | **236** |

### 2.2 域内分组（评审单位 = 组，不是单个 L2）

以行为动作域（527 个）做了首轮关键词聚类实验：

| 语义组 | L2 数 | 实例 |
|---|---|---|
| 手部操作 | 45 | 295 |
| 工作职业 | 42 | 3,008 |
| 身体动作 | 28 | 45 |
| 日常生活 | 22 | 1,455 |
| 体育运动 | 20 | 145 |
| 自然交互 | 17 | 325 |
| 饮食相关 | 12 | 45 |
| 移动出行 | 11 | 323 |
| 冲突对抗 | 11 | 30 |
| 言语交流 | 9 | 241 |
| 情感表达 / 感知认知 / 社交礼仪 | 7 | 238 |
| **多义（命中多组）** | 141 | 5,717 |
| **未分组** | 162 | 1,998 |

**结论**：关键词粗筛能稳定分出 ~10 个核心组（224 个），但 141 个多义 + 162 个未分组（合计 303 个）需要**模型二次聚类**（每组 20-40 个名称喂给三模型背靠背，和骨架评审同一套评审局）。预计行为动作域最终落成 12-15 个评审组。

### 2.3 每组评审看什么

1. **归属**：组内 L2 是否该留在本域
2. **平行重复**：组内是否有两套结构装同一批东西（呼应 16,875 域内重复实例）
3. **同义合并**：近义分支合并（沿用批 1/批 2 的合并裁定模式）
4. **命名**：段名多义 / 含斜杠的旧账（现存 2 处「帝王蟹/蟹」类）

流程铁律不变：**评审局出裁决表 → 用户点头 → 执行器落盘 → 逐条改动清单**。

## 5. 纪律（沿用）

- 原始文件永不修改；每批落盘前建 `backup/<批次>_前/`
- 先裁决表后落盘，用户点头才动手
- 每批落盘后出「名称：X → Y」逐条改动清单（对话要点 + `outputs/迁移改动清单_*.md` 全量）
- 执行器套路：备份 → 映射 → 改名先行 → 碰撞并集 → 中英同映射 → 数量校验 + EN 首段禁含中文断言

## 4. 构建与复现

```bash
python3 scripts/v3/build_v3.py      # 生成 V3 树 + ip_instances_v3.json
python3 scripts/build_tree_v3.py    # 生成 build/tag_tree_v3.json
python3 scripts/gen_html_v3.py      # 生成 tag_tree_explorer_v3.html
```

继续扩充方式：在 `scripts/v3/exp_*.py` 的 `INSTANCES` 追加条目（键 = "一级分支/二级/叶子"），
或 `BRANCH_ADDITIONS` 追加子树，重跑管线即可（幂等，自动去重合并）。

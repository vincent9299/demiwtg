# V3 融合世界标签体系 · IP 段扩充说明（2026-08-13）

> 目标：V2 → V3，以"覆盖全"为第一优先，逐层、逐分支扩充 IP 标签的**分支**与**实例**；本轮**不做跨分支去重**，同一实体允许多视角挂载。

## 4. 构建与复现

```bash
python3 scripts/v3/build_v3.py      # 生成 V3 树 + ip_instances_v3.json
python3 scripts/build_tree_v3.py    # 生成 build/tag_tree_v3.json
python3 scripts/gen_html_v3.py      # 生成 tag_tree_explorer_v3.html
```

继续扩充方式：在 `scripts/v3/exp_*.py` 的 `INSTANCES` 追加条目（键 = "一级分支/二级/叶子"），
或 `BRANCH_ADDITIONS` 追加子树，重跑管线即可（幂等，自动去重合并）。

## 5. 遗留事项（下一轮）

1. **采集配置未同步**：`image_collect_config*.json` 仍是 V2 版，含 88 个失效 job（军火/炸弹/跨品类等已删节点）+ 大量新叶无 job，需从 `ip_instances_v3.json` 重新生成；
2. **数据集缺口**：`科技与数字 IP` 仍无 dataset 分片产出；
3. **深度扩充空间**：品牌/真人与人物等大类可继续加细（当前叶子均值约 8.7 实例，可提到 15+）；地标可细化到城市级叶子；
4. **V2 review 的 P1/P2 问题**（命名规范统一、语义归属裁决、去重）按用户指示本轮未处理。

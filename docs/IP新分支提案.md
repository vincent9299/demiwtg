> **状态：P1–P6 已全部落地** `V2融合世界标签体系_清洗版.txt`（2026-08-10），IP 顶层现共 19 个分支。

> 命名风格对齐现有体系：内容类 `XX IP`、商业类 `XX品牌`、模板类 `XX类别—传播范围/呈现载体`。

## 提案总览

| # | 新分支 | 定位 | 优先级 | 与现有分支的关系 |
|---|---|---|---|---|
| P1 | 非遗与传统手工艺 IP | 非物质文化遗产、传统技艺、民俗 | 高 | 艺术与文物 IP 的"活态"延伸 |
| P2 | 美食 IP | 美食文化、地方风味、饮食地标 | 高 | 品牌 IP 内"餐饮品牌"是商业侧，本分支是文化侧 |
| P3 | 自然生态与动物 IP | 珍稀动物、国家公园、自然遗产 | 高 | 吉祥物与形象 IP 只管商业化拟人形象，本分支管真实生态 |
| P4 | 教育与科普 IP | 科普内容、教育机构、知识传播 | 中 | 填补现有完全空白 |
| P5 | 科技与数字 IP | 航天、互联网产品、AI 应用 | 中 | 著名载具/新兴物种的"文化侧"收拢 |
| P6 | 历史与文化遗产 IP | 朝代、历史事件、文化带、考古文明 | 中 | 地标 IP 管"点"，本分支管"面" |

## 落地建议

1. **去重约定**（新增前先确立，避免二次融合污染）：
   - 戏曲：作品视角（内容作品 IP）vs 非遗视角（P1）
   - 海洋生物：新兴物种类别 vs P3
   - 航天器/人工智能：著名载具/新兴物种 vs P5
   - 文物：馆藏本体（艺术与文物 IP）vs 文明语境（P6）
2. **facet 模板沿用**：`—传播范围`（全国/区域/国际）、`—呈现载体`（互动数字/视听/静态图像）与现有体系一致。
3. **建议推进顺序**：P1 > P2 > P3 > P4 > P5 > P6（高优先级三个先落地，中优先级三个视业务需要）。
4. 各分支二级节点下的三级细分（菜系、剧种、朝代等）可作为空壳模板待填充，或先只建二级骨架。

## 交叉点归属约定表（2026-08-10 第三批次落地）

P1–P6 落地后，部分概念在多个分支间天然存在交叉。本轮 phase3 已处理的标 ✅，未处理的标 ⏳。约定如下，避免重复建树：

| 交叉点 | 主归属 | 副归属/视角切分 | 状态 |
|---|---|---|---|
| 戏曲 | `内容作品 IP/戏曲舞台作品 IP`（作品视角，具体剧目） | `非遗与传统手工艺 IP/曲艺与传统戏剧 IP`（剧种、流派、传人） | ⏳ 两边保留，按视角区分 |
| 海洋生物 | `自然生态与动物 IP/珍稀动物 IP/海洋生物 IP` | — | ✅ 已删 `新兴物种类别/海洋生物IP类别` |
| 虚拟偶像 | `虚构角色 IP/虚拟偶像`（偶像化运营的虚拟形象） | — | ✅ 已从 `真人与人物 IP` 迁出 |
| 人工智能 | `科技与数字 IP/人工智能 IP`（AI 作为文化符号） | `新兴物种 IP`（AI 主体本体，原"人工智能主体"已迁入 `科技与数字 IP/人工智能 IP`） | ✅ AI 主体已迁入 `科技与数字 IP` |
| 航天器 | `著名载具 IP/著名航天器`（实物载具） | `科技与数字 IP/航天科技 IP`（科技文化符号） | ⏳ 两边保留，按视角区分 |
| 文物 | `艺术与文物 IP/文物与馆藏 IP`（馆藏本体） | `历史与文化遗产 IP/考古文明 IP`（文明语境） | ⏳ 两边保留，按视角区分 |
| 老字号 | `品牌 IP/餐饮品牌`（商业主体） | `美食 IP/美食地标 IP/老字号 IP`（文化地标） | ⏳ 两边保留，按视角区分 |
| 体育 | `真人与人物 IP/体育明星`（个人）+ `真人与人物 IP/真人团体组合/体育队伍`（团体） | `赛事 IP/体育赛事 IP`（赛事） | ⏳ 三段切分 |
| 虚构超自然存在 | `虚构角色 IP/志怪鬼怪形象`（再生人、幽灵、神等） | — | ✅ 已从 `新兴物种类别` 迁入 |
| 吉祥物 | `吉祥物与形象 IP`（拟人化商业形象） | `品牌 IP`（品牌本体） | ⏳ 一个品牌的商业主体在 `品牌 IP`，拟人形象在 `吉祥物与形象 IP` |

**约定原则**：同一概念在多个分支出现时，必须明确"主归属"（实体本体挂的那一侧），副归属侧只描述该实体某一视角（作品/非遗、本体/语境、主体/形象等），不重建子树。

## 落地建议

1. **去重约定**（新增前先确立，避免二次融合污染）：
   - 戏曲：作品视角（内容作品 IP）vs 非遗视角（P1）
   - 海洋生物：新兴物种类别 vs P3
   - 航天器/人工智能：著名载具/新兴物种 vs P5
   - 文物：馆藏本体（艺术与文物 IP）vs 文明语境（P6）
2. **facet 模板沿用（双 profile 受控）**：按节点原型使用两套受控维度，不混用。
   - **Profile A** `—传播范围`（全国/区域/国际传播）+ `—呈现载体`（互动数字/视听/静态图像）：内容/文化/个人类 IP。
   - **Profile B** `—组织范围`（全国级/国际级/地方级）+ `—运行方式`（公共管理/公益/商业运行）：`品牌 IP` 全部子类，及 真人与人物 IP 的团体/组合子类。
   - 具体实物/事件类分支（内容作品、艺术与文物、地标、武器、著名载具、赛事、潮玩互动、乐园节庆）不适用 facet，保持无 facet。详见 `清洗记录.md` 第八批次。
3. **建议推进顺序**：P1 > P2 > P3 > P4 > P5 > P6（高优先级三个先落地，中优先级三个视业务需要）。
4. 各分支二级节点下的三级细分（菜系、剧种、朝代等）可作为空壳模板待填充，或先只建二级骨架。

## 全量逐分支 Review（2026-08-13）

本轮对 21 个一级分支逐一 review 并增补，IP 段节点 770 → 869。主要变更：

- **新增二级分支**：音频节目作品（内容作品）、摄影名作（艺术与文物）、传统武术与体育（非遗）、科研机构 IP（组织机构）、国际美食（美食）、学科竞赛 IP（教育科普）、潮玩商品角色（虚构角色）、互动娱乐（潮玩互动）、奖项典礼 IP（赛事）、宠物/玩具/文创文具/传媒娱乐/能源化工/建材家装/物流配送/电信运营商品牌（品牌 IP）等。
- **删除**：品牌 IP/跨品类品牌类别（模板占位）、武器 IP/军火与炸弹（通用分类残留，含"汽车炸弹"等不适格节点）、赛事 IP/电子竞技赛事（品类叶子并入 电竞 IP/电竞赛事 IP）。
- **修复**：`前沿科技/生物科技` 叶子丢失（2026-08-10 清洗时遗失，本轮恢复）；真人与人物 IP 政府官员/外交官三级嵌套拉平。
- **保留现状**：文物与馆藏/陶瓷器子树保留原粒度（用户决策）。

**新增边界约定**：

| 交叉点 | 约定 |
|---|---|
| 电竞赛事 | 统一归 `电竞 IP/电竞赛事 IP`；`赛事 IP` 只管实体体育与奖项典礼 |
| 电竞选手/解说 | 归 `电竞 IP/电竞明星 IP`，不进 `真人与人物 IP/体育明星` |

## 2. P1 · 语义归属与约定违背（建议本轮修复）

1. **乐园节庆 IP/综艺娱乐 归属存疑**：喜剧综艺/文化综艺/真人秀/竞技综艺/音乐综艺 与"乐园/节庆"语义无关，而 `内容作品 IP/影视作品/综艺` 已存在——等于综艺出现双轨并行分类，违背"主归属"原则。建议迁入 `内容作品 IP`，或保留但明确"场景综艺 vs 作品综艺"视角约定并写入交叉点表。
2. **企业家 vs 行业标杆人物 约定被实例违背**：边界约定为"企业家=创始人/经营人物；行业标杆=技术专家/工匠"，但宗庆后、张瑞敏、王传福、董明珠、雷军、马化腾 6 人**同时双挂两侧**。建议按约定单轨化。
3. **历史古人/政治家 时间边界不清**：富兰克林·罗斯福同时挂在 `政治与社会人物/国家领导人物` 与 `历史古人/政治家`——罗斯福为近现代人物，不应入"历史古人"。建议明确分界（如 1911/1900 为界）并修正实例。
4. **武器 IP/著名军机 ⊂ 著名载具 IP/著名飞机**：跨分支外延重叠，交叉点归属约定表未覆盖（约定表只有"航天器"条目）。著名军用飞机（歼-20、B-2 等）归哪侧无据。建议在约定表补"军用飞机：武器 IP 管作战平台视角，著名载具 IP 管载具本体视角"或单轨化。
5. **城市文旅吉祥物 下 城市赛事吉祥物 vs 体育赛事吉祥物 交叉**：福娃、冰墩墩两个实例均双挂。建议合并为一个叶子，或明确"赛事性质 vs 主办城市"判据。
6. **品牌 IP 内容平台品牌 vs 流媒体平台品牌 重叠**：爱奇艺同时挂 `互联网与软件品牌/内容平台品牌` 与 `传媒娱乐品牌/流媒体平台品牌`。建议明确判据或合并。

## 3. P2 · 命名规范与结构优化（建议排期处理）

1. **" IP" 后缀双轨制**：710 个叶子中仅 45 个带 " IP" 后缀，且全部集中在 3 个分支——组织机构 IP（23）、电竞 IP（11）、城市与地域 IP（11）；其余 18 个分支叶子均无后缀。更突出的是 `教育与科普 IP` 内部混用（`学科竞赛 IP` 与兄弟 `科普内容`、`教育机构` 并存）。建议统一（全去后缀更简洁），或至少在 `清洗记录` 中把双轨规则成文。
2. **武器 IP 命名混杂**："著名X"系列（著名军机/著名枪械…）与泛类目（军用武器装备/海军武器装备/防御体系）混排；后三者语义偏"泛指品类"，与 IP 段"命名实体"定位略有出入。
3. **真人与人物 IP/名人 分支名过宽**：与 影视明星/音乐艺人/体育明星 并列易混淆，建议更名"社会公共人物"。
4. **歌手 子类判据混杂**：主唱（角色）/乡村流行歌手（风格）/男低音歌手（声部）/摇滚明星（定位）四种判据混用；且 `说唱歌手` 与兄弟 `说唱艺人` 跨层重复。
5. **科学文化人物 继承自通用分类的过细叶子**：`科学家/社会科学家/经济专家/微观经济专家、计量经济学家`（深度 7）、`语言学家/心理语言学家、语音学家`——IP 语境粒度过细、实例难稳定，建议收拢为"经济学家、语言学家"。同类的 `教育家/学术人员/教授` 中"学术人员"为单子冗余层，建议拉平。
6. **工程师/黑客** 挂载不当：黑客不必然是工程师，建议删除该叶或另挂。
7. **音乐作品/器乐与影视原声带 vs 影视音乐** 概念重叠，建议合并或明确"配乐 vs 歌曲"判据。
8. **正交子类问题**：`超级英雄与漫画角色/反派角色` 与兄弟（按地域/作品分）正交；`动漫角色/儿童动画角色` 与 `中国动画角色` 判据交叉。建议成文"按主属性归类、辅助视角不建节点"。
9. **陶瓷器子树**（用户已决策保留原粒度，仅记录）：`瓷/瓷器/骨灰瓷` 父子命名缠绕（瓷器 ⊂ 瓷），`斯波德陶瓷`（品牌）与 `瓷器`（材质）并层，`陶器/彩釉` 是工艺非器类。

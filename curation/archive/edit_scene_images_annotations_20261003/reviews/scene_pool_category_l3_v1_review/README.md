| 阶段 | 数量 | 含义 |

| 实际视觉输入 | 500 | 全局输入/调用预算；其余候选未执行视觉判断 |
| 有效视觉标注 | 495 | 4 条无效响应、1 张读图失败 |
| 视觉 keep 原图池 | 255 | reject 224、hold 16；机器 keep，全部 status=unreviewed |

183,013 是尺寸通过候选数，123,603 是本次每概念限量后的候选数，255 是实际完成视觉筛选的保留数。没有“18.3 万张均已审完、最终仅剩 255 张”的事实。

500 张按现有 SHA 顺序及每概念限额选择，不是按场景/大域配额抽样；不能将 255/500 当作全量候选的可用率，也不能称这批覆盖所有类别。模型判断的表达形式：photo 234、render 11、illustration 9、diagram 1。标签涉及公共空间、城市/历史建筑、室内、自然环境，也有器物、食品、肖像、商品特写；这些是模型多标签，不是互斥的人审统计。255 张全部来源标记 not_verified，不能据此宣称已验证真实摄影来源。

## keep / reject / hold 分布

| 决定 | 全量分类数（7,917） | 分类占比 | 有效图片标注数（495） | 有效图片占比 |
|---|---:|---:|---:|---:|
| keep | 3,214 | 40.60% | 255 | 51.52% |
| reject | 2,154 | 27.21% | 224 | 45.25% |
| hold | 2,549 | 32.20% | 16 | 3.23% |

图片另外 5 条是技术失败，不记为 reject/hold。若以全部 500 张输入为分母，则 keep/reject/hold/技术失败分别为 51.0% / 44.8% / 3.2% / 1.0%。这里只覆盖实际视觉批次，不外推全量候选。

场景 keep 240/255（94.1%），建筑与基础设施 412/464（88.8%），自然景观 202/240（84.2%）。hold 较多的大域有动物 230/368（62.5%）、人物与人体 292/565（51.7%）、行为动作 432/875（49.4%）。声音 reject 246/267（92.1%），文字与信息图形 174/198（87.9%）。比例分母均为各大域的分类数，不按成员概念数加权。

完整 29 大域见 [分布 CSV](category_domain_distribution.csv)，机器可读计数见 [分布 JSON](decision_distribution.json)。Notebook 预览格同步显示总分布与全部大域分布。

## 24 张视觉抽看结论

抽样方法：SHA 排序的 255 张中，用 seed=20260927 随机取 16 张，再按标签补 8 个边界样例。以下是助手对显示像素的审阅意见，不是用户人审、不改写原池；边界样例有目的选择，不能据此估计总体误判率。

| 示例 | 像素与来源标签 | 对编辑原图的判断 |
|---|---|---|
| #232 / 00a07d6c6575 | 喷泉广场、铺装地面及建筑 | 存在可见地面和清楚透视，可作场景候选；具体 add 仍需核对尺度、接触、遮挡与概念 |
| #175 / 007680764f47 | 地图墙前有椅子、落地灯，地面留有空位 | 有较清楚的室内承载区域，适合进一步匹配新增/修改题 |
| #081 / 003a465217de | 有许多行人的广场 | 可作场景候选，但对象定位和避免误改周边实例更难 |
| #093 / 00403488b53e | 俯视桌面、吐司与餐具 | 可研究食物/器物修改或小尺度新增；已有物体占据较多空间 |
| #031 / 0019c3498d8b、#038 / 001db9fac188 | 白底单件器物、留声机 | 更适合与既有目标相关的修改；不应当通用“空场景”使用 |

| #020 / 0013044e77ef | 风车照片上有贴纸和装饰文字 | 需检查装饰污染，当前 keep 不能直接交付使用 |
| #003 / 00020c3f18fa、#004 / 00021b22c832 | 密集商店、桌面茶壶近景 | 空位少、遮挡或虚化明显；可用性高度依赖具体操作，不宜作通用新增题底图 |

结论：已经召回一批有价值的场景和对象图片，但“共用 add 场景”与“概念对象修改原图”混在一个 keep 池里；还存在来源错绑、拼版/文字污染及空间判断过宽。当前 255 张应继续作为候选，不直接当作 255 张合格 benchmark 原图。后续应根据题目概念核心和操作，匹配可见承载区域、目标尺度、视角、遮挡及光照；素材保留不等于某道题可可靠完成和判分。

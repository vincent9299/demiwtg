# 二级 taxonomy 分类粗筛 · 2026-09-27

用户明确采用全库概念 taxonomy 前两层作为分类、第一层作为大域；4B 只看分类信息，不提供概念或样例。此方案替代此前“末端路径 + 6 个代表概念”的试验，历史记录保留。

输入固定 `datasets/master_concepts.lance@2`。按正式 concept_row/category_memberships 算子和标准 Dataset 在临时隔离根汇总，结果：

- 385,292 个概念。
- 2,754 个分类，29 个大域。
- 425,351 条概念—分类关联；同概念多个深层路径落入同类时只计一次。
- 模型 payload 全部只有 domain/category，例如 `{"domain":"动物","category":"动物 / 鸟类"}`；成员数量仅留在表中，不传概念名、别名、代表样例或数量。

分类只用于宽松召回：保留有稳定可用子范围的类别，明确无关才排除，无法判断的 hold 留表待复查。keep 分类关联全部成员概念后，再取公共 images@9 做尺寸和视觉筛选。2,754 是粗筛单位数，不是原图池大小或入池保障。

Notebook 使用 `scene_pool_category_v1`，taxonomy_depth=2，无手写类别白名单或概念条数截断。文本预算 3,000；图片每概念最多 4 张、全局最多 5,000 张，短边严格 >1024。through=categories 可先看分类结果，再改为 image_inputs/pool 继续。

验证：原图测试 32 项通过，模块布局检查 1 项通过；覆盖二级归并、同概念同类去重、多分类召回、短路径、分类输入无概念材料、成员变化仍复用分类响应，以及原有图片尺寸/引用/标注流程。全量元数据汇总无模型调用、未改公共表，临时表已清理。完整 2,754 分类和视觉建池批次尚未运行，未把代码测试当作分类质量评测。
